# 网盘搜索（pansou）

面向飞牛 fnOS 的网盘资源搜索与转存工具：从 Telegram 频道检索夸克分享链接，自动检测链接有效性，一键转存到自己的夸克网盘，支持手动选择保存目录。

默认端口 **8909**，打包为 `.fpk`，应用中心手动安装。

## 功能

- **多频道搜索**：并发检索配置的 Telegram 频道，标题匹配排序，严格匹配开关
- **链接有效性检测**：搜索结果自动标记「有效 / 失效」，失效链接禁止转存
- **一键转存**：转存时弹窗浏览夸克目录，可选根目录或任意子目录
- **手动链接**：粘贴分享链接 + 提取码，解析后转存
- **夸克账号**：Cookie 有效性检测、保存目录浏览
- **代理支持**：通过本地代理访问 Telegram，内置代理连通性测试
- **封面显示**：结果卡片展示频道封面（经服务端白名单代理）

## 安装

1. 下载 `pansou-1.0.0-x86.fpk`
2. 飞牛应用中心 → 手动安装
3. 打开「网盘搜索」→ 设置页填写：
   - 夸克 Cookie（浏览器登录 pan.quark.cn 后复制请求头 Cookie）
   - 代理地址，如 `http://127.0.0.1:7890`
   - 频道列表（每行一个 Telegram 频道 ID）
4. 保存后点「测试 Cookie」「测试代理」确认可用

## 使用

| 操作 | 说明 |
| --- | --- |
| 搜索 | 输入关键词，从配置频道检索 |
| 转存 | 点结果里的「转存」→ 选择目录 → 转存到当前目录 |
| 解析 | 粘贴链接和提取码，可先解析再转存 |
| 链接状态 | 搜索后自动检测，失效链接会标红并禁止转存 |

## 构建

```bash
./build/build.sh x86    # 输出 dist/pansou-<version>-x86.fpk
```

依赖：Go 1.24+（仅标准库）。

## 说明

- 应用以 root 运行，便于读写配置与访问网络
- 夸克 Cookie 属于敏感凭证，仅保存在本地 `var/config.json`
- 搜索源为第三方 Telegram 频道，内容与链接有效性不受本项目控制
